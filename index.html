Cara menggunakan kalkulator

  1. Untuk input harga buku, currency yang digunakan adalah Rs (Rupee)
  2. Untuk input berat buku, cari section "BOOK DETAILS - see all details - item weight"
  3. Total harga adalah total per 1 buku; mencakup harga buku + handling + packaging fee, belum termasuk ongkir dari Jakarta Pusat
  4. Jika ingin melakukan pembelian lebih dari 1 buku,
    1. Input harga & berat buku satu per satu
    2. infokan seluruh pesanan buku di "form fix order", lalu admin akan menginfokan harga total akumulatif
