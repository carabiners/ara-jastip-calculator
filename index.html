Cara menggunakan kalkulator

  1. Untuk input harga buku, pastikan currency yang digunakan adalah Rs (Rupee)
  2. Untuk input berat buku:
    1. Cari section "BOOK DETAILS - see all details"
    2. Input detail di section "Item weight"
  3. Total harga adalah total per 1 buku; mencakup harga buku + handling + packaging, tapi belum termasuk ongkir dari Jakarta Pusat
  4. Jika ingin melakukan pembelian lebih dari 1 buku:
    1. Input harga & berat buku satu per satu
    2. Infokan seluruh pesanan buku di "form fix order", lalu admin akan menginfokan harga total akumulatif
